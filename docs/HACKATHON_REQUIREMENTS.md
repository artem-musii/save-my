# WebMCP Challenge requirements snapshot

Verified against the official pages on 2026-09-02:

- [OpenAI WebMCP Challenge](https://openai.com/webmcp-challenge/)
- [Devpost overview](https://webmcp.devpost.com/)
- [Official rules](https://webmcp.devpost.com/rules)

The current deadline is September 3, 2026 at 1:00 PM Pacific Time (22:00 in Europe/Madrid). Judging weights are equal: WebMCP Leverage, Execution, Potential Impact, and Creativity & Ambition. WebMCP Leverage is the first tiebreaker.

Submission preparation must include a working public URL, public source repository with a detectable open-source license, English description and testing instructions, and a public YouTube demonstration under three minutes with audio. Source must contain real `document.modelContext.registerTool(...)` usage. Judges use the ChatGPT in-app browser or supported Chrome WebMCP environment.

## Repository compliance

- [x] All application source, generated assets, migrations, and run instructions are present.
- [x] A root MIT \`LICENSE\` is present and package metadata declares MIT.
- [x] Bundled font notices and the full SIL OFL 1.1 text are distributed with the app.
- [x] The app uses real \`document.modelContext.registerTool(...)\` registration through the shared registry boundary.
- [x] English project, testing, WebMCP, security, accessibility, and deployment documentation is present.
- [x] The project was created during the August 25–September 3 submission period.
- [ ] Public live URL is deployed and verified while signed out.
- [ ] Public YouTube demo is under three minutes, has English audio, and contains no unlicensed music or third-party marks.
- [ ] The final Devpost form is submitted before the deadline.

Re-check the official rules immediately before final submission because they can change.
