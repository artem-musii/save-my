## Local Wow Project contract proof

The local proof combines the deterministic domain fixture with a hermetic Chrome model-context bridge that captures and invokes the real page registration callbacks. It proves the application/tool contract and visible human boundary, but it is not evidence of a native host or model choosing and executing the write sequence:

1. The captured `create_company` account callback created an empty private company named **Wow Project** and reported the workspace callbacks ready.
2. `get_workspace_summary` returned baseline version 1 with zero items.
3. `draft_company_blueprint` staged **40 items, 78 connections, 8 critical workflows, and 47 relationship groups** as one component with zero isolated refs. It returned version 2, `baselineChanged: false`, and `humanReviewRequired: true`.
4. The domain contract returns the same proposal ID/version for an exact same-key retry and rejects changed payload reuse.
5. The visible human **Apply company map** action created the baseline; the bridge did not accept it on the agent's behalf.
6. The registered callbacks resolved exact fixture IDs and `design_failure_scenarios` staged three materially distinct scenario drafts without changing the baseline.
7. Separate deterministic service tests stage three fully authored repair options and prove each comparison reaches zero blocked workflows.
8. The Chrome repair journey proves a representative new item and its changed paths are absent in Before, visible in After, and applied only by a visible human action.

## Differentiation from Replay

Replay is an excellent narrow incident workspace with unusually dense testing, provenance, exports, and submission evidence. SAVE MY… should not imitate its traffic-scene domain. Its stronger competitive position is:

- broader repeat value across real organizations and industries;
- a one-call, contract-checked path from company description to a connected operational graph;
- deterministic multi-point business-disruption cascades rather than a single case reconstruction;
- three explicit recovery strategies with effort, time, residual-risk, and before/after proof; and
- multi-company personal workspaces backed by PostgreSQL, with editable people, roles, assets, schedules, ownership, and paths.

Replay currently has stronger public-release evidence and more exhaustive automated coverage. SAVE MY… narrows that gap through a bounded native read-only trace, hermetic real-callback write coverage, a documented eval specification, a production database rehearsal, and a concise judge path. A win cannot be guaranteed; the objective is a clearer WebMCP necessity and a more reusable product story.

## Three-minute judge path

1. Open Diamond Apps and run the stored three-person failure.
2. Ask the page-connected Site Tools agent to inspect and stage three complete repairs; switch Before/After and show zero blocked.
3. Keep acceptance visibly human-only.
4. Ask the agent to create an empty Wow Project company and stage the complete salon map through native tools.
5. Show the native result counts, the illustrated proposal graph, and the baseline/draft boundary.

Do not deploy, publish, record, or submit until the user explicitly approves those actions.
